# ++C Intermediate Language (PPCIL)


The purpose of this language is be an easily interpretable, translatable and compilable instruction-wise representation of the ++C language. The IL is made so that an application can be run on any system without any significant overhead, while still compiling just one executable. The instruction set of this IL is made so that PPCIL performance is comparable to native performance.
