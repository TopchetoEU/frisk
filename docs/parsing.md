The first major step in the compilation of frisk is the parsing. In this stage, the raw source is converted into a raw abstract syntax tree. This tree is yet to be hidrated - no type, name, call or other resolutions are made yet.

To allow a versatile and reusable parsing system, a mechanism called "protocols" was implemented. In short, whenever a parsing context is being initialized, an array of parsers is put into it. Whenever a parsing is invoked, an array of protocols are passed, too. The parser may check if a protocol is present. For example, the variable declaration parser could check if the `std::storage` protocol is present. If it isn't, the parser will just return a "pass" result.
